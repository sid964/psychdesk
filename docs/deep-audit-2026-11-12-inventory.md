## Dependency map

- `index.html` loads theme before body; deferred `app.js` exposes `PsychDeskCore`. Study extensions use that core and optional globals.
- `cloud.js` owns notebook/Drive operations; `firebase-sync.js` owns per-account Firestore snapshots and account transitions; `drive-persistence.js` optionally talks to the disabled-by-default durable backend.
- `app.js` routes study tabs and owns local snapshots, timer and modal lifecycle. `motion-runtime.js` owns animation playback; `motion.js` adapts render/modal events; CSS layers supply presentation and decorative motion.
- `autopilot/studio.js` owns account-scoped IndexedDB jobs/artifacts/activity and a text-analysis Worker; `autopilot/preparation.js` and `autopilot/imports.js` provide approval/import workflows.
- `world/world-bridge.js` translates application events and same-origin iframe messages to browser history. `world/index.html` loads `world-ui.js` independently of graphics, then dynamically loads `world.js`.
- `world.js` imports pinned CDN Three.js/OrbitControls plus local landscape/places/life modules. Only the bridge can enter study tools; the World has no study-record write path.
- `pdf-reader.js` uses PDF.js from CDN and Drive blobs from cloud.js; `study-session.js` stores account-scoped resumable metadata; notes/highlights use existing study data.
- `sw.js` precaches same-origin shell assets, leaves third-party APIs alone, fetches navigation from network and uses the current release cache offline.
