# Optional local pose assets

Place your own `idle`, `resting`, `sleeping`, `walking`, `waving`, `pointing`, `thinking`, `celebrating`, `syncing`, `disconnected` and `pet-react` PNG/WebP/SVG files here for a local-only build, and configure `window.PsychDeskCompanionArtwork` before startup. Files in this folder are ignored except this README. GitHub Pages cannot serve uncommitted files; use Preferences → Private pose for browser-local imports on the hosted site.
