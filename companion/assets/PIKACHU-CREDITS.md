Changes for PsychDesk: removed an unrelated placeholder, welded coincident vertices, cleared split normals, added subdivision smoothing, transformed the mesh to a centered web coordinate system, normalized yellow shading, and converted its geometry, normals, UVs and PNG textures into a compact gzip model. A native WebGL renderer adds procedural head, ear, paw, tail and foot motion. Source UV layouts and recognizable geometry are retained. The approved studio render supplied in the conversation used this base model.
